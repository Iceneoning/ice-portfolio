# ADR-0002：动效与媒体体验策略

- 状态：设计阶段采纳，尚未通过实机测试
- 范围：首页首屏、项目卡片、案例页视频、转场和背景
- 进一步约束：[动效运行时架构](../architecture/04-motion-runtime.md)、[媒体性能管线](../architecture/06-media-performance.md)、[动效分镜](../design/03-motion-storyboard.md)、[导航转场 ADR](ADR-0003-navigation-transitions.md)

## 核心判断

作品本身是展品，动效只能帮助观看者理解层级、空间与内容。**拒绝以随机粒子、无意义发光、廉价悬浮按钮构成主视觉。**

## V1 采用

1. Hero 优先展示一张经过艺术处理的**真实 UE 作品封面或关键画面**，标题始终可读。
2. 以低对比度冰晶、折射边界、高光遮罩为视觉识别；动态效果局部、有限、低频，基于透明度和 transform，避免大面积 backdrop-filter 动画。
3. 项目卡片微交互统一：轻量图层移动、图像缓慢缩放或淡入，仅在指针精度允许时启用 hover。
4. 项目视频默认显示 poster；用户主动播放或满足明确的可见性/带宽条件才加载媒体。循环静音预览不是必要条件。
5. 页面转场优先原生 MPA + 浏览器跨文档 View Transitions（经兼容性验证可选）；不默认启用 Astro `ClientRouter`。GSAP 仅在艺术分镜确实需要时间轴时按需添加。
6. 所有关键内容在 JavaScript 不加载、动效不播放时仍能访问。

## 媒体分级

| 等级 | 内容 | 处理方式 |
| --- | --- | --- |
| P0 | 标题、定位、首张项目封面 | 首屏优先；封面响应式；明确宽高防布局跳动 |
| P1 | 后续项目截图 | 延迟加载、压缩与尺寸适配 |
| P2 | 详细案例录屏 | poster 占位、用户点击加载，提供字幕/文字说明 |
| P3 | 装饰折射、视频片段/音效 | 可完全关闭，不影响理解，网络差自动降级 |

## 体验安全边界

- 尊重 `prefers-reduced-motion`：取消视差/复杂转场/循环背景，只保留最小状态变化。
- 不自动播放带声音的视频；不做页面加载后自动发声。
- 任何轮播有明确控件、焦点与暂停能力；不强制用户等待动画后才能阅读。
- 暗色透明卡片必须有合格的前景/背景文字对比；文字不可压在不可预测的高亮游戏区域。
- 不依赖高频 scroll 监听计算位置；需要时采用 IntersectionObserver 或 CSS scroll-driven（先验证兼容性与回退）。
- 明确约束移动端数据用量；首屏不可将多个 MP4 作为必要请求。

## 待验证

- 真正视觉焦点应使用 RTS 与 BA 中哪一个实机片段。
- 背景折射图层是否需要动态模糊以及在低配设备上能否保持流畅。
- 设计评审通过前不实现复杂动画；先出静态设计稿/可交互低成本原型。
