# 交互、响应式与无障碍规范

## 导航与访客路径

- Header 在所有页面提供直达 `/projects/`、`/about/`、`/resume/` 的入口。
- 项目卡片整体可点击，键盘焦点可见；若卡片内有独立外部链接，不制造嵌套链接。
- 详情页面展示「返回项目列表」与可分享 URL，长案例提供锚点目录。
- 外链明确标识；简历按钮只指向真实、已审核的文件。
- 路由跳转不使用强制长动画；浏览器返回时保持可预期体验。

## 动效语法

| 场景 | 建议 | 不使用 |
| --- | --- | --- |
| 首屏进入 | 一次性的文本/封面层级显现 | 逐字闪烁和长时间片头 |
| 项目 hover | 小幅 transform、光线位置响应 | 卡片不断漂浮或鼠标跟踪粒子 |
| 项目切换 | 短暂淡入/合理共享元素 | 连续全屏遮挡 |
| 正文图片 | 点击放大、有关闭与键盘返回 | 只能靠鼠标点关闭的 modal |
| 锚点导航 | 保持语义和定位准确 | 阻碍用户到达内容的 scroll hijack |
| 装饰背景 | 默认静态/低频率 | 始终消耗 GPU 的大面积实时模糊 |

所有运动参数集中在 design tokens，便于统一调整；避免单个组件内部任意设置一组不一致的持续时间。

## Responsive 设计

- 测试基准宽度：360/390px（手机）、768px（平板）、1280/1440px（桌面）。
- 手机首屏：文字、关键图、主 CTA 可读且顺序清晰；不依赖 hover。
- 项目卡从大屏图文分栏变为单列顺序阅读，不强行保留不对称版式。
- 代码片段保留语法高亮和复制按钮，但必须有横向滚动或行折叠，不出现页面级横向溢出。
- 导航触控目标建议不小于 44 × 44 CSS px，菜单正确处理焦点。
- 大图明确宽高或比例，减少 CLS。

## 动效与设备降级

- 支持 `prefers-reduced-motion: reduce`：关闭持续循环、视差和非必要过渡；内容无需动画也可发现。
- 对细指针 hover 与触控设备分别优化。
- 视频播放由明确点击触发；支持暂停、静音、字幕/文字摘要。
- 图片加载失败时保留 ALT、背景与标题，不让项目卡整体消失。
- 页面不依赖 JavaScript 才能展开核心技术说明。

## Accessibility 验收

1. 所有按钮、链接、菜单、弹层仅键盘可操作，焦点可见。
2. 页面拥有唯一 H1、合理 H2/H3 结构、main/header/nav/footer landmark。
3. 有信息价值的图片写准确 ALT；装饰元素为空 ALT 或 aria-hidden。
4. 文字和控制元素对比度按 WCAG AA 检查，不能让半透明背景导致低对比。
5. 视频应有语义说明；有语音或关键声音时提供字幕/文本转述。
6. 不出现无需同意即播放声音、闪烁敏感内容或阻碍浏览器返回的转场。
7. 分享链接、下载链接、GitHub 链接应有明确文字，而非只有图标。

## 暂不实现

- 可拖拽 3D 场景、站点音效开关、主页实时渲染 UE 场景。
- UI 主题编辑器、多语言全量站、复杂状态管理和全局 JS 动画引擎。

这些都属于完成内容和基本可用性后的独立提案。
