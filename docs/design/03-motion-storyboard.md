# V1 动效分镜：从视觉意图到可执行动作

> 目标是**美感、空间关系和作品叙事**，不是通过数量制造存在感。以下分镜与时长都是原型初稿，需用户审美评审和设备测试。

## 1. 整体艺术语言

主题：**冰晶与折射的光学留白 + UE 实机画面的电影式展陈**。

核心观感应是“光轻轻扫过作品、空间逐步显露”，而不是“水晶碎裂、粒子爆炸、整站旋转”。绘制层次时优先用真实截图、节奏、光影、对齐关系；背景始终作为展厅而非另一件需要观看的作品。

**唯一的高关注度动效放在首页 Hero，其他交互主动降低音量。**

## 2. 首页分镜（Motion Beats）

| Beat | 时机/诱因 | 视觉意图 | 技术实现优先级 | 失败/降级 |
| --- | --- | --- | --- | --- |
| H0 | HTML 到达 | 标题、真实作品封面即可见 | Astro 静态 HTML + 优化图 | 无 JS 即最终状态 |
| H1 | 进场的一次性短过渡 | 字体、光线与画面依层次建立空间，不是逐字闪烁 | CSS/WAAPI | reduced motion 直接显示 |
| H2 | 用户移动指针到封面 | 少量折射高光偏移，反馈“玻璃框架” | CSS hover，必要时微量 JS | touch 没有 hover，版式完整 |
| H3 | 访客滚动到精选项目 | 项目图像与标题从已有排版层级轻柔显现 | IntersectionObserver + CSS（仅当必要） | 显示静态内容 |
| H4 | 项目卡 hover/focus | 真实游戏画面轻微强调，明确可点击 | CSS transform / focus-visible | 无 hover 仍可点击 |
| H5 | 点击项目 | 封面在页面间保持光学连续性，阅读视线落到详情 | 优先试验原生 MPA View Transitions | 直接完整导航 |

时间轴设计必须能被**直接跳过**，不能挡住 CTA、链接、媒体 controls 或滚动。

## 3. 页面级动效

### 首页 Hero

- 由 **标题层、封面层、辅助折射层、CTA 层** 组成。背景可有薄雾/折射纹理，但绝不使用实时昂贵的大面积模糊当作布局前提。
- 进入时根据空间从背景到文字建立关系，避免多个元素以不同方向乱飞。
- 重点镜头建议以真实 UE 游戏画面完整可读为优先，光效只发生在图像边缘或未承载正文的留白。

### Featured Projects

- 更接近“展品陈列”，每个项目只有一个主要动态反馈。排序和阅读次序不受动画改变。
- 对 RTS 可强调建筑/资源系统画面，对 BA 可强调 Gameplay/推车玩法，但最终须依据真实录屏与美术构图决定。
- 文案先说明个人职责，技术标签从属，不用流行词拼贴。

### 项目详情

- 首屏分为项目封面、项目事实和进入正文的视觉引导；重点从「电影画面」过渡到「技术说明」。
- 架构图、代码和技术验证面板优先稳定、可选中、可放大；不能持续漂浮。
- 有图片对比时允许轻量 Before/After 组件，但需键盘与触控回退，且图片来源清晰。

## 4. 设计 Token 初稿

| Token | 初始建议 | 意图 |
| --- | --- | --- |
| `--motion-fast` | `160ms` | 按钮 / 焦点反馈 |
| `--motion-normal` | `280ms` | 卡片和浅层过渡 |
| `--motion-reveal` | `480ms` | 标题/展品的一次性显现 |
| `--motion-hero` | `720ms` | 首页视觉层级形成的完整时间窗（非强制等待） |
| `--ease-emphasis` | `cubic-bezier(.22,1,.36,1)` | 平稳减速 |
| `--reveal-distance` | `12px` | 避免元素大幅移动 |
| `--hover-scale` | `1.02` | 游戏图像轻强调 |

数值只是起点；动效的是否保留看眼睛、性能、手感与可访问性四类验收，不追求精确神奇参数。JS 禁用和 reduced-motion 必须仍可用。

## 5. 高保真评审素材清单

- 桌面 1440px：完整首页首屏、首个 Featured Projects、一个项目详情的技术章节。
- 手机 390px：Hero、项目卡、技术详情代码/架构图区域。
- 三段录屏对比：静态、标准动效、reduced-motion。
- 提供至少一个无特效版本做对照，观察折射是否真的提升质量。
- 如缺少真实作品封面，原型素材必须清楚标「视觉占位」，不得误认为 UE 成品。

## 6. 明确禁止的反模式

- 页面初始化时黑屏数秒、载入环节播放不可跳过 Logo。
- 滚动抢夺、鼠标拖拽才能切换作品、连续自动轮播。
- 大量装饰性粒子、冰晶碎片漫天飞舞、字幕和画面同步疯狂运动。
- 在视觉高光上铺大量半透明正文导致文字看不清。
- 为加载视频造成的等待做假进度动画，而不提供静态观看。
- 依赖过场动画才能知道作品名称或找到联系方式。

## 7. 审美验收

**S1 阶段评审实际构图，不以此 Markdown 文档替代视觉稿。**

通过标准：一眼能记住页面气质、一眼知道是 UE 作品集、项目画面先于装饰、动效连续且克制、默认与降级均不出现廉价突兀效果。
