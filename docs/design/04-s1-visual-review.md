## 两套比较方向

### A. CRYSTAL / 冰晶展厅（默认）

- 色彩：深海军蓝、冷白、冰蓝细高光。
- 视觉特征：折线切角的展示框、微弱细网格、规则式几何轮廓、少量玻璃折射。
- 氛围：UE 系统工程 / 技术展览 / 深邃安静。
- 风险：容易变成通用科技 SaaS 首页，因此强制用真实游戏封面替换中间占位几何，不堆叠功能卡片和发光线框。

### B. NOCTURNE / 夜色画廊

- 色彩：暖黑、象牙白、香槟金、低对比的美术馆灯光。
- 视觉特征：柔和的展柜光、英文 serif 强调字与更克制的透明层。
- 氛围：电影幕后作品册 / 数字艺术展陈 / 编辑式排版。
- 风险：技术定位容易被过度的画册气质稀释；职业定位和系统示意必须保留。

**两套方案共用信息架构，仅比较艺术语言。** 与此前需求一致，不在第一轮同时改页面结构和风格导致难以比较。

## 动效最小叙事

- 页面加载：一轮轻柔的 Hero 入场；HTML 内容在 JS 失败时已可见。
- Hero 展框：默认静态几何与高光，不播放重复的 3D 旋转或粒子。
- 卡片：鼠标 hover 的轻微明度变化与箭头位移，焦点由系统轮廓明显标注。
- 页面转场：仅在正式站阶段验证 MPA View Transitions；S1 页内仅通过真实锚点滚动模拟动线。
- 移动端：所有内容单列，不依赖 hover；减少动画偏好时完全关闭装饰性过渡。

## 暂未锁定的内容

1. 是否保留英文排版为主、中文为辅，或让中文更突出？
2. Hero 真实素材用 RTS 还是 Blitz Archive？取决于截图的美术表现与可公开状态。
3. 最终是否坚持冰晶元素，还是更偏向电影式夜色画廊？
4. 折射层是否过于“技术 UI”，是否要更少线框、更大面积真实作品？
5. 首页是否展示第三个轻量项目？不应为了凑数量牺牲质量。
