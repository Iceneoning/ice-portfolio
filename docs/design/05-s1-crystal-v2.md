# S1 V2 — 冰晶不是颜色，而是界面语言

- 时间：2026-10-08
- 状态：设计修订原型，**尚未经浏览器截图验收与用户美术确认**
- V2 原型：[icefolio-v2.html](../prototypes/icefolio-v2.html)
- 用户认可 V2 主体冰晶方向，但要求继续美化背景；新版本见 [V3 背景专项](06-s1-glacial-background-v3.md)。
- V1 旧版：[portfolio-s1.html](../prototypes/portfolio-s1.html)
- 用户反馈：上一版虽然冰蓝，但有明显的通用 AI 科技模板感，缺少与“冰晶”真正相关的视觉元素。

## 失败分析

第一版的“冰晶”基本是色值和名称；主体依然是霓虹圆环、笛卡尔网格、矩形卡片、统一的英文大标题。换成紫色就能变成任何科技模板，这说明设计语言缺少辨识度。**问题不在 CSS 量不够，也不在动画太少，而在形态与视觉叙事没有来源。**

## V2 核心设计语法

| 冰晶的真实特征 | 网页构图中的对应关系 | 禁止误用 |
| --- | --- | --- |
| 多个不规则晶面 | Hero 大型多边形切面，每一面有不同透光与冷暖反射 | 所有面都用完全相同的玻璃蓝色 |
| 光线折射 | 游戏截图作为“透过冰层看到的世界”，边缘少量偏移彩光 | 全站文字都套色差滤镜 |
| 晶体边缘高光 | SVG facet 边线、仅一次经过的 glint | 无限扫光、强发光描边 |
| 夹层与纵深 | 少数跨层冰晶遮罩、图片层、远景云雾分开 | 用十层背景模糊代替画面 |
| 冰裂面与切口 | 封面不规则裁切、展品边缘的光折线 | 高频噪声、密密麻麻的 HUD 网格 |
| 清冷、安静 | 大幅留白、轻量中英文标题、图片优先 | 大量紧密卡片、按钮堆砌 |

注意：“冰晶”应当是一种**视觉结构**，而不是到处散布雪花图标。Logo 采用六重对称纹理；Hero 采用不规则晶体剖面；项目封面采用局部切面；文章详情回归平静的阅读版式。

## V2 的具体改变

1. **首页 Hero**：改为偏编辑设计的大中文标题“让规则凝成世界”，保留小号 UE / C++ 岗位定位。标题和晶体视觉在构图上彼此呼应，弱化模板式英文口号。
2. **独立冰晶视觉**：使用原创内联 SVG 多面多边形，使用带透明度的冷色/乳白/细微紫色面片模拟折射。不是下载的普通玻璃模型，也不是冒充 UE 截图的合成画面。
3. **项目图片槽**：待加入真实 RTS / Blitz Archive 截图时，图片本身仍是主角；角落保留一两片晶体棱面，绝不整个封面刷蓝。
4. **作品目录**：用开放式排版、大图片、细线索引与留白代替双列实体面板。
5. **技术详情**：冰晶语言渐弱，把技术图、代码和验证信息作为视觉中心，减少背景装饰对阅读的干扰。
6. **动效**：一轮柔和晶面入场 + 边缘光线渐隐；仅精细指针在 Hero 区小幅移动晶体和折射图层，没有自动运行的全屏粒子循环；reduced-motion 完全静态。

## 视觉边界

- SVG 是**设计概念里的冰晶图形**；其中的游戏截图窗口是文字明确标识的占位，不得在未核实截图时说它是 RTS 作品画面。
- 即使未来使用高质量 UE 实机图，晶体也应当只是“图像边缘的光学器件”，不能遮住重要 Gameplay 行为。
- 不追求物理准确的实时光学渲染；V2 用 SVG 面片和 CSS 模拟晶体透光。真实性和效果需要实机浏览器截图评审。
- 不为制造“冰感”把所有东西都做成尖锐菱形；正文、可访问控件、图表都保留稳定常规阅读格式。

## 用户评审议题

- 大晶体会不会太像品牌海报而抢走 UE 项目？
- 大中文标题比 V1 的大英文 slogan 是否更有个人表达？
- 项目封面角落的晶面是否有“冰”感，还是像裁切的科技几何？
- 是否需要真实冰晶摄影/渲染素材进一步增强真实质地？若需要，单独制作或核验版权再接入。
- 详情页的艺术装饰是否足够克制？
