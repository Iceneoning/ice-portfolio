- V2 参照：[S1 V2 原型](../prototypes/icefolio-v2.html)
- 背景资源：`../prototypes/assets/glacier-wall.svg`、`../prototypes/assets/frost-veins.svg`

## 一、反馈与设计意图

用户已认可 V2 的冰晶方向，但指出整站背景仍偏常规深色网页。本次不是叠加全站蓝色渐变和雪花动画，而是将页面设计为**可以感知冰壁、冰缝、透雾与折射光的空间**。

**情绪关键词：** 低温、透明、宁静、远景、透光、被冰层包裹的展厅。

**唯一主角：** UE 项目游戏画面和工程案例。背景必须托举画面，不作为独立表演对象。

## 二、背景的五个物理与视觉层级

| 层 | 物理联想 | 技术实现 | 交互约束 |
| --- | --- | --- | --- |
| G0 深冷底 | 冰层深处的环境光 | 多点低对比径向渐变 + 深蓝底色 | 永远不动画，不用纯黑 |
| G1 冰壁 | 冻结形成的不规则、半透明冰层 | 原创 SVG 多面片路径，两个对置冰壁面 | 只能出现在视口边缘并受渐变 mask 控制 |
| G2 冻纹 | 沿冰层应力传播的分叉裂纹 | 原创 SVG 不均匀分叉线，按区域裁剪 | 中心正文区极弱，避免“科技网格” |
| G3 冷雾 | 不同景深间的冷空气与散射 | 低透明径向渐变 | 不用全屏高强 blur，不能损失对比度 |
| G4 焦散/折射 | 光穿过冰晶后的不规则反射 | 极少量不均匀渐变及 conic 光纹 | 局部出现，不做扫光循环/炫光插件 |

这五层都在 `.frozen-scene` 内作为 `aria-hidden` 的装饰层，只由 CSS 绘制，不参与点击、焦点、内容读取或布局。

## 三、分区艺术控制

### Hero：带有透光深度的冰晶空间

- **背景色：** 左侧文字区更暗、右侧晶体附近出现透雾冷光。
- **冰壁：** 左侧半隐藏冰面，右侧大而透明的冰壁，避免两侧同样亮。
- **冻纹：** 右缘可见，中心标题区减弱。
- **焦散：** 只在 Hero 晶体周围少量出现；不沿整屏扫动。
- **验收：** 一眼能看出冰晶/冰层氛围，但必须先看到职业方向和作品窗口。

### Selected Work：退后半步的冰面

- 主体换为大幅真实项目截图，晶面只守在版面边缘。
- 第一张图附近背景稍微提亮，第二张图区域更深，保持“展品之间的呼吸”。
- 不能让背景与卡片的切面折光相互竞争。
- 作品没有图片时使用明确的「占位」标签，不假装是一张 UE 游戏图。

### 分区间的冰折层

- 不用横向赛博光线或者随机雪粒。
- 使用一层大角度、低对比的冰架截面，将上一屏冷光延伸到下一屏，形成连贯空间感。
- 分隔区不阻碍滚动，也没有必须等待的动画。

### Engineering Focus：接近静态的背景

- 信息密度提高时，冰壁基本退场，冻纹透明度压到很低。
- 减少半透明卡片，优先文字的层级、留白、细分割线。
- 背景不能影响代码或系统架构阅读。

### Project Detail：走入冰层内部

- 更深的层理蓝 + 右侧微弱冰裂面。
- 项目封面保留清楚的展示面积，不叠加大面积蓝色滤镜。
- 技术说明区仅允许低对比背景，架构图和代码颜色要被保留。

## 四、真实 UI 和装饰层隔离

```text
section.hero / section.section-work / section.case-study
  ├─ .frozen-scene [aria-hidden=true]      纯装饰，不参与布局/焦点
  │    ├─ .ice-wall ...                    原创冰壁 SVG
  │    ├─ .frost-lines                     原创冰裂 SVG
  │    ├─ .cold-mist                        低透明 CSS 渐变
  │    └─ .refracted-light                 局部光纹
  └─ .wrap [z-index:2]                     所有标题、项目卡、链接与正文
```

CSS 的 isolation、z-index、overflow 由 section 承担；不能把绘制层插入正文的可交互层中。背景 SVG 放在 `docs/prototypes/assets`，实际迁移 Astro 后建议移到 `src/assets/visuals/` 或可缓存的静态资源目录。

## 五、V3 验证用的 A/B 开关

原型右下角设置了“背景层：开启/关闭”控制：

- 默认开启，查看 G0–G4 的完整氛围。
- 点击关闭，隐藏新增冰壁、冻纹、雾层以及背景过渡中多余晶面，观察是否真的提升艺术质量。
- 开关是**设计评审专用**，不进入正式作品集的 UI。
- 即使鼠标移动特效被 reduced-motion 或触屏跳过，背景开关仍要可操作。

注意：关掉场景层时，基础色彩渐变和 V2 的大晶体仍然存在；这是对比 V3 的**增量背景层**，不是对比纯白网页。

## 六、施工与性能边界

- 所有 SVG 均为手工设计的静态图形；不实现真正的物理光线追踪、动态折射渲染或 Three.js 背景。
- 不创建 JS 每帧更新背景的主循环，不为冰雾做永不停止的 CSS 呼吸动画。
- 大型模糊与滤镜只在静态背景小范围使用；移动端通过媒体查询收缩冰壁、降低强度。
- 尊重 `prefers-reduced-motion`，不以动画作为展示作品信息的前提。
- 网络请求至少需要核实 SVG 资源大小；实际首屏 LCP、CLS 和交互延迟需到正式预览环境实测，不能由方案文档宣称通过。
- 背景效果不应该将按钮放在半透明玻璃上造成文字对比不足。
- 若实机测试显示某背景层破坏主体质量，按 G4 → G3 → G2 → G1 的顺序逐级撤销。

## 八、与 S2 的连接

用户确认 V3 后，不是把原型文件整份复制进 Astro，而是拆成：

1. `GlacialBackdrop.astro`：单个场景组件，`variant=hero|work|reading|case`，所有层纯装饰。
2. `ice-scene.css`：光学图层与媒体查询，集中维护对比度和性能降级。
3. `HeroArt.astro`：大晶面与真实 UE 封面，不混进背景类。
4. `ProjectExhibit.astro`：项目图片、介绍及局部晶面描边。
5. `DesignTokens`：背景强度、文字对比、媒体断点共用变量。

视觉方案已落地成可审查的 HTML/CSS/SVG **原型**，还不是正式页面的实现或验收结果。
