## 本轮明确的审美纠偏

用户不认可 ambientCG Ice 001 这类暗色湖冰和无规则裂面。真正需要的是**自然结晶规律产生的精致雪花结构**：六角晶体、六重对称、细分叉、枝晶霜花、晶面透光。

不要将用户偏好的“冬天冰晶”偷换成冰裂纹、赛博网格或透明几何技术卡片。之前的抽象多面晶体 Hero 仍是 V4 构图基础，但后续新材质统一向雪晶/霜晶审美靠拢。

## 当前形态局限

第一版**仍然偏线条插画和几何枝晶，不等于摄影级雪晶**。已用 Edge 1440 宽屏浏览器渲染对照并保存截图。能明确看出六个辐射分支与自然枝晶概念，但是现实雪晶的细微毛边、表面颗粒、内反射、色散和层厚变化尚未模拟出来。

因此先在页面背景小范围使用，**不要直接将这一版作为占满整屏的照片替代品**。如果后续用户感觉不够自然优美，我们再判断是手工改 SVG、尝试预烘焙更精致的光学图形，还是最后再找经授权的真实雪晶微距摄影。

## V2 显微镜参考纠偏（2026-10-08）

**用户提供实际雪晶参考图，对比指出原版雪晶仍像矢量线框，与真实天然雪晶质感相差很远。** 参考图体现的核心并非单纯六重对称，而是晶轴的光学厚度、明亮的镜面反射、复杂侧向板晶、密集的三级分枝，以及极微小的不对称和局部色散。

- 旧版：`public/visuals/hex-snow-crystal.svg`（保留，适合作为小图标或抽象图形）。
- **新研究稿：** [雪晶 V2 比较页](../prototypes/snow-crystal-v2.html)；素材 `public/visuals/dendritic-snow-crystal-v2.svg`。
- 实际 Edge 截图：[雪晶 V2 对比截图](../prototypes/snow-crystal-v2.png)。
- 新 SVG 使用六条径向主晶轴、厚薄变化的枝晶玻璃棱面、多层微分枝、双重高光/微弱泛光，底色切换可检视网站适配。
- **仍未通过审美验收：** 新图虽然复杂度和高光大幅提高，但依然可见高度周期性与重复叶片轮廓，不是摄影级雪晶；尚不能说“已接近真实雪花”。大约 364 KB 的未压缩 SVG 和多次滤镜引用需要另做体积与性能优化，**不允许未经测试直接全尺寸部署为网页主要画面**。
- 目前仅放在单独的美术研究页，不替换用户已确认的 Astro 主页，也不修改 RTS/Blitz 项目页面。
- 下一步优先：研究真实晶体形状的噪声扰动/不规则板晶边界/多尺度散射和非均匀光源，再与用户参考对照；如果程序化模拟仍显著不如自然材质，回到用户之前许可的真实摄影素材方案，但不使用暗冰或湖面裂纹。

### 用户参考图提炼的验收标准

1. **剪影：** 6 条主干清晰，每条分枝局部自然不对称，但不会失去整体晶体结构。
2. **高光：** 以冷白高反射边缘为主，内部半透明暗部和明部交错，不能整幅均匀“霓虹描边”。
3. **立体度：** 晶轴呈玻璃棱柱，板晶有多层边缘、细纹和局部厚度。
4. **微细节：** 枝晶上有更细的分叉和细碎自然肌理；在缩小预览时不产生过密的栅格或条纹。
5. **网站适配：** 首页可以局部引入，但背景不能抢过 UE 作品与正文。
6. **性能：** 质量合格后才能考虑导出优化 SVG 或尺寸适配 WebP/AVIF，并实测移动端性能。

## 玻璃雪晶 PNG → WebP 网站接入试验（2026-10-08）

目标：用户从 ChatGPT 下载的透明雪晶图已具备实际晶柱和局部高光，比线框 SVG 更符合首页主视觉。试验**仅针对现有 V4 Hero 的右侧美术图层**，不修改首页主标题、作品选集、独立项目路由或已确认的主要布局。

- 原素材：`透明背景上的冰晶雪花.png`，1254×1254 RGBA，真实 Alpha。
- 在当前对话工作容器里生成桌面用 `portfolio_iceflake_960.webp`（约 344 KiB）与手机用 `portfolio_iceflake_480.webp`（约 91 KiB），保留透明度。
- 在浏览器中对一个**独立的 V4 风格对照页**进行 1440px / 390px 的视觉检查，确认图像加载、A/B 方案切换与无横向溢出；本地完整可运行 ZIP 随对话交付。
- 远程已创建 `docs/prototypes/cinema-v4/glass-crystal-preview.html` 与 `glass-crystal-preview.css`：整页继承 V4 并加入开关，**没有覆盖正式 `index.html`**。
- 浏览器素材引用规划：`public/visuals/portfolio_iceflake_960.webp` 和 `public/visuals/portfolio_iceflake_480.webp`。远程机器尚未找到 PNG 原文件；对应两个 WebP 必须先同步到远程仓库，方可评审该版本。若资源未提供，对照原型自动保留原有晶面。
- 已提供可直接解压到仓库根目录的素材包：`iceflake_v4_project_assets.zip`。解压到 `H:\vs_code\ice-portfolio\` 后新 WebP 路径与预览引用一致。
- 这次不是 UV/PBR 材质重建：高光已在图片里烘焙，不带可分离法线贴图或实时光线追踪。

### 实际设计判断与未决项

在独立浏览器 A/B 图中，雪晶的强镜面高光终于可以在深蓝背景上直接体现；但用于首页必须控制占比和遮挡。当前预览适度调低不透明度，桌面集中在右侧、移动端放在正文下方，并加入非常弱的柔光。不要同时叠放旧的几何晶体和新雪晶，避免画面杂乱。

**未完成：** 远程 WebP 实际落盘、远程浏览器包含真实素材的最终 V4 原型渲染、用户艺术确认、正式 Astro 接入、性能评估。浏览器中的本地视觉演示不能替代正式工程可用性测试。原始 PNG 仍建议由用户保留。

## 与已确认 V4 的结合

- 保留「让规则凝成世界。」主标题，不恢复早期「请选择一个世界」。
- 首页冰晶与页面版式不推翻：在 Hero 背景中只使用少量、低透明六角雪晶；边缘的“冰壁”改用枝晶霜纹。
- 作品区「作品选集。」仍以真实 UE 截图为最终视觉主体。封面没有经核实媒体时继续明确写占位，不做伪实机画面。
- 详情正文中雪晶背景必须比首页弱，架构图/代码优先可读。
- 不添加全屏雪花动画或随机粒子，避免廉价动效；减少动效设置必须保持静态可读。
