## 问题

在前一版玻璃雪晶试验中，雪花被完整地展示在首屏右栏，像贴上去的巨型徽章。纵然玻璃质感成立，其与背景、文字和展厅入口缺少叙事联系，且视线过度集中于雪花本体。

## 本方案：晶体不是摆件，而是环境的一部分

1. **裁切而不是完整居中。** 玻璃雪晶从画面右侧、画面外延伸出来，主要留下数条主晶轴和玻璃支枝；避免正面展示完美六角雪花徽章。
2. **增加物理语义。** 右侧是由冰晶、半透明切面与少量折光线组成的倾斜冰壁；雪花被视为冰壁内部的结构。光学高光始终在背景层，左侧人眼优先读标题。
3. **编排有主次。** 左侧「让规则凝成世界。」是第一视觉焦点；右侧雪晶只作为环境第二焦点；下方「作品选集。」和两部游戏海报承担真正的信息交互。
4. **控制亮度。** 透明 WebP 约 0.65～0.75 不透明度、水平渐隐与局部投影光。禁止整片泛光和照亮页面所有文字。
5. **场景纵向衔接。** 雪晶的边缘切面指向下方选片展厅，下面的展示空间继续保持深蓝色，不额外堆叠多枚相同雪花。
6. **手机独立布局。** 主标题、职业定位、说明与按钮在前；仅在正文下方右侧展示被裁切的部分雪晶，避免与文字或 CTA 重叠；进一步降低不透明度。

## 两层视觉资产的职责

- 带 Alpha 的 WebP：负责真实玻璃高光和精细晶枝，不作为 PBR UV 贴图。
- CSS 光学层：负责斜切冰壁、局部透明/折射方向、边缘柔和反光、遮罩、响应式裁切。
- 不用 WebGL、不持续旋转、不做无意义漂浮；`prefers-reduced-motion` 保证静态可读。
