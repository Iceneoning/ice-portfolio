## 二、新雪花定位

正式方向：**日系幻想游戏里的冰系纹章（Anime Fantasy × Winter Morning）**。不是显微摄影，不是写实玻璃，不是简单六边形线框，不是 Shader 展示，也不是带满屏金边和粒子的二游运营页。

主体在极浅雾蓝中具有清晰而优雅的六向主剪影，可适度设计化变形，保持精致、轻幻想、冰蓝、珍珠青、少量暖白的味道。

纹章分四层：

1. **晶核**：细六角宝石、珍珠白小星点、两个方向的晶面高光。主体填色，不靠强描边撑起造型。
2. **六条冰羽**：细长菱片与羽枝组合，中心密、末梢疏，保留对称的整体构图但允许插画式装饰收笔。
3. **断续丝带/弧形纹线**：两段有方向感的轻圆弧和局部铭记，不包成封闭、机械的魔法阵。
4. **微弱星屑**：不超过十数处，均为明确排版位置，不随机生成雪雨。

材质以**插画式半透明色块、赛璐璐式冷暖分面、少量银白切边高光**为主。禁止将纹章整枚变成反光金属徽章或直接复用旧 V7 发光线条。

## 三、页面使用

**首页**：保持 V7 Hero 文字、按钮、网格比例不变。右栏放 V8 SVG 主纹章，偏右、不过度切边，周围是极轻暖白天光和一两道装饰线，不能喧宾夺主。首页**不再加载 V7 optics.js**，避免 Shader 雪花叠影。空白/降级时也应排版完整。

**作品选集**：只给卡片极低透明度的雪纹角饰或单段晶羽线。真实 UE 媒体待补时保留诚实的技术文字和占位，绝不能用幻想风 CG 冒充游戏实机截图。

**技术案例页**：主纹章退出首屏主体，最多小型品牌符号或背景角饰。面试官先看到项目名称、职责、技术内容和下一部入口。背景仍然是 V7 的晨光浅色系。

**手机**：390 CSS px 先显示标题、介绍、操作按钮，右侧纹章自然落到正文下方，无覆盖和横向滚动。

## 四、动效与技术

- 主纹章可选 7–10 秒的 1%–2% 轻柔呼吸和轻度位移；**不连续旋转、不漂浮满屏雪花粒子**。
- 几个局部高光可以偶尔移动，但静态态必须已经足够美；如果出现廉价广告扫光就直接删除。
- SVG 作为主造型的唯一来源，CSS 暖冬背景与很少量阴影负责融合，前端不需要 Three.js 或新的渲染依赖。图形学可负责局部柔光，而不能代替插画造型。
- SVG 标记为装饰性图片（空 alt）；HTML 标题和链接永远可读。prefers-reduced-motion: reduce 停止所有非必要动画。
- 保持原生跨文档链接，严格区分设计占位和真实 UE 项目事实。
