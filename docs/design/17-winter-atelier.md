# Winter Atelier / 冬日世界工坊

2026-10-09。用户反馈上一轮「没有美感」。本轮停止在抽象几何插画上微调，重做场景、排版与视觉层次，替代设计 16。以下描述是实施方向，不表示用户已经认可。

## 画面

明亮冬日场景、深蓝文字、暖白留白与少量金色。首页的具体焦点是雪中工坊、蓝色穹顶和通往暖光门厅的阶梯。文字区以渐变遮罩保持可读，右侧保留建筑与地景，顶部保留完整建筑剪影。手机保留同一场景，将主体接到文字下方。

主标题采用本地可用的中文宋体；英文标题采用 Georgia，正文用无衬线。保留「让规则凝成世界。」「作品选集。」。减少重复的微小标签，深蓝按钮与首屏具名项目入口负责引导浏览。

作品区采用两列大幅画面与简洁正文，手机单列。RTS 装饰画面是雪中聚落，Blitz 是冬日档案馆；它们保持冰蓝、奶白与暖光的共同色彩。案例页采用同样的字体和对应的装饰画面，个人职责与技术事实仍是内容主体。

## 真实性

三幅图片通过内置 ImageGen 工具专门生成，属于网站的 AI 概念插画，不能当作项目真实环境、游戏截图、技术成果或个人 UE 美术作品。页面有可见的非 UE 标注，源文件说明与完整提示词见 `src/assets/atelier/`。真实 UE 媒体区域继续独立标为待补；审核通过的真实封面仍通过原有媒体字段显示。

## 技术

Astro Image + Sharp 在构建时生成 WebP / srcset，首页主图优先加载，封面延迟加载。没有客户端脚本、粒子或大幅旋转。只保留品牌标记微弱呼吸与封面轻微放大；降低动效偏好关闭它们。链接使用原生导航，键盘有可见焦点，案例首屏 / 页尾的换片和返回选集继续复用。
