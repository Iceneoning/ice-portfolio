# V1 施工路线（阶段依赖与安全边界）

- 状态：S1 美术基线已批准；**S2 Astro/MDX/Tailwind 静态工程源码已建立，依赖安装等待工作区安全确认，构建/浏览器验收尚未执行**。
- 原则：**设计与内容先于复杂动效；最小可用发布先于扩展功能**。
- 约束：所有施工均在 `ice-portfolio` 仓库内进行；不顺手修改博客 `fuwari`、UE 项目或磁盘映射。
- 可执行任务的更小拆分、输入输出与阻塞条件见 [03-work-packages.md](03-work-packages.md)。
- 精美动效的验收必须结合 [分镜文档](../design/03-motion-storyboard.md) 与 [运行时架构](../architecture/04-motion-runtime.md)，而不是只看动画库和 FPS。

## S2：工程基座

拟施工任务：

- 初始化 Astro + TypeScript + pnpm，并锁定依赖版本。
- 配置 `@tailwindcss/vite`、MDX、Content Collections 与 Zod schema。
- 创建 BaseLayout、基础导航、页面文件路由、tokens.css、global.css。
- 首页保留 V3「让规则凝成世界」冰晶主视觉和原始中文/英文文案，随后实现影院式海报选片墙，每张海报通过原生链接进入 `/projects/[slug]/`，详情页有返回大厅和下一部作品入口，不保留 V3 的首页长篇案例段落。
- 添加项目列表/详情静态生成；一开始全部使用明确标注的开发占位数据，不发布为真实成果。
- 配置基础 SEO / 404 / 图片优化 / 媒体组件。
- 保持原生 Astro MPA 路由；原生跨文档 View Transitions 仅在 S4 评审后渐进启用，不在脚手架阶段引入 ClientRouter。
- 创建 `pnpm build`、Astro 检查与基础测试可执行的工程脚本。
- 基于实际框架版本验证是否需要 Wrangler 静态资源配置细节；不在 S2 自动部署。

**完成条件：** 依赖安装与构建真实通过，页面可本地打开，内容 schema 报错可阻断错误项目。

## S3：真实作品内容

- RTS：视频、系统结构、本人职责和一条可复现实例优先完成。
- Blitz Archive：Lyra 借用范围、Gameplay 系统、实机演示和验证范围。
- 第三/第一人称练习与 WHITE FANG 465 根据素材质量决定详情页深度。
- 外部源码、简历和个人邮箱全部在公开前审核。

**完成条件：** 首页至少 2 个可以直接进入的高质量技术案例；所有演示和技术声明有来源。

## S4：网页实现

- 组件由小到大：导航 / 按钮 → 项目卡 → 项目详情组件 → 首页主视觉。
- 先实现静态排版和真实内容，再加入 CSS 细节、精细的进入动画与交互反馈。
- 没有通过视觉评审的动画不进入正式分支；低配设备必须自动降级。
- 链接和焦点态不依赖 JS。

**完成条件：** 3 种设备尺寸布局统一、导航可靠、分享与 PDF 链接真实、媒体控制正常。

## S5：验证

- 先按 [验收清单](02-acceptance.md) 做链接、schema、构建和可访问性校验。
- Lighthouse 分别测桌面和模拟移动端，并记录环境；实际设备测试视频和滚动。
- 对照 Git diff 审查新增依赖和媒体总量，移除误加入的内部资料（需按 MCPX 正式确认流程操作）。
- 核对所有「已实现 / 已验证 / 本人负责」的描述与 UE 工程证据。

## S6：发布

- 先开 Cloudflare 预览并验证 Workers 静态路由。
- 审核域名、DNS、浏览器安全头、媒体公开范围和可回滚版本。
- 用户明确批准后再绑定独立子域名；**不能修改 fuwari 的构建与 DNS 配置**。
- 记录正式发布的 Git SHA、部署配置和人工验收结果。

## 阶段禁止跨越的边界

- 没有 S1 设计稿，不提前做装饰性特效以免反复推倒。
- 没有真实内容，不上线宣称真实性能/网络测试的技术案例。
- 没有用户确认的公开资料，不上传 PDF、邮箱或整套 UE 工程。
- 没有完成 S5，不以「页面能打开」替代验收。
- 没有用户授权，不执行 Cloudflare 发布、域名改动、Git push 或删除现有文件。

## 文档更新机制

- 技术方案变更：更新 ADR → 相关 architecture → roadmap → acceptance。
- UI 变更：更新 design + 新旧页面对照图，再进入实现。
- 真实项目范围变更：更新 content 清单和对应 MDX，并核对简历文案。
