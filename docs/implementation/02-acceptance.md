# V1 验收矩阵（上线前逐项打勾）

> 当前状态：**NOT RUN**。下列数字是规划目标，不是测试结果。每轮施工应附实际运行日期、环境、命令和结果。

## A. 功能与内容

- [ ] 首页和 `/projects/`、`/projects/[slug]/`、`/about/`、`/resume/` 均可直接访问及刷新。
- [ ] 点击项目卡进入正确案例；导航、返回、分享、锚点、外链都有效。
- [ ] 项目索引和首页取自同一 Content Collection；添加一篇合法 MDX 自动生成对应页面。
- [ ] 草稿项目不会出现在正式构建、站点地图或搜索页面中。
- [ ] 无封面/缺少职责字段/错误 schema 会给出明确构建错误或受控回退。
- [ ] 可公开的简历 PDF 真实存在且可下载；未提供前显示非误导性的替代入口。
- [ ] 404 有清晰返回路径；不出现死链或空白屏。
- [ ] 页面标题、description、OG 图片和 canonical 链接正确且无占位域名。

## B. UE 项目真实性验收

- [ ] 首页和详情的贡献、版本、测试范围与公开简历一致。
- [ ] RTS：地图、建筑、能力、资源职责描述与实际记录匹配；**没有**将命令系统归于本人。
- [ ] RTS：对未完成的多人测试不使用「已通过网络同步/丢包验证」类陈述。
- [ ] Blitz Archive：明确本人扩展内容与 Lyra 复用内容的区分。
- [ ] WHITE FANG：尚未解决的镜片/材质或 Final QA 问题如有出现须如实写明。
- [ ] 每项性能/网络/测试数字都附测试环境、日期和可追溯报告。
- [ ] 所有截图/视频均来自真实作品或明确标注为设计草图，不混淆二者。

## C. 前端技术验收

- [ ] `pnpm install --frozen-lockfile` 可安装（脚本存在并经项目核对后执行）。
- [ ] `pnpm build` 成功，输出是预期的静态资源。
- [ ] Astro TypeScript / Content Collections 检查通过（根据实际脚本选择命令）。
- [ ] CSS 和交互没有需要 React 全站 hydration 的无意义依赖。
- [ ] 自动化浏览器冒烟测试：首页、索引、至少两个案例、404、导航均通过。
- [ ] 依赖锁文件、图片位置和发布媒体均在仓库可追溯。

## D. 视觉与交互

- [ ] 首页访客能迅速看到 UE / C++ 方向与真实作品，而不是一屏装饰图。
- [ ] Desktop 1440px、Tablet 768px、Mobile 390px/360px 逐页截图评审。
- [ ] 技术长文、表格、代码片段、视频控件均不会造成页面横向溢出。
- [ ] 屏幕旋转、窄屏菜单、触控与鼠标 hover 均有合理反馈。
- [ ] 滚动转场不会阻塞交互；`prefers-reduced-motion` 时可关闭非必要运动。
- [ ] 项目图片具有正确色彩与构图，没有被统一冰蓝滤镜遮蔽。
- [ ] 视觉审美由用户单独评审通过；**Lighthouse 高分不能替代美术验收**。

## E. 无障碍

- [ ] 键盘能遍历所有互动控件，焦点可见，ESC 可退出弹层。
- [ ] H1/H2/H3 层次合理，图像 ALT、按钮名称、landmark 正确。
- [ ] 一般文本最低按 WCAG AA 4.5:1、大号文本 3:1 目标校验。
- [ ] 图片缺失/视频未下载/JS 关闭时，主要内容仍可理解。
- [ ] 媒体有用户可见播放/暂停控制；有语音时有字幕或转写。
- [ ] 不会在未经用户互动时播放带声音的媒体。

## F. 性能与网络预算（目标，不是当前测量）

- [ ] 以 Web Vitals 常用 good 阈值为目标：**LCP ≤ 2.5s、CLS ≤ 0.1、INP ≤ 200ms**；实际按测试环境报告。
- [ ] 本站首屏不依赖视频完成加载；移动视口优先载入一张响应式封面。
- [ ] Lighthouse 桌面/移动单独记录 Performance、Accessibility、Best Practices、SEO，并保留原始报告和测量日期。
- [ ] 大体积视频不在初始页面同时下载；未点击播放不提前加载全量。
- [ ] 监测各视口总传输量、字体数量、第三方脚本数量；视情况设可实现预算，不先捏造实际体积。
- [ ] 实际手机检查滚动、焦点、媒体播放和 GPU 开销，没有持续卡顿或过量耗电。

## G. 发布与安全

- [ ] 预览/正式 Cloudflare Workers 路径可访问，静态 404 行为已实测。
- [ ] HTTPS、页面刷新、OG 分享预览、直接进入深层路由正常。
- [ ] 博客构建、导航、域名配置没有因本项目被擅自修改。
- [ ] 公开资源扫描：无令牌、.env、私人文件、受限资产、内部 IP、未授权截图。
- [ ] Git SHA / 发布版本可追溯，能够回滚。
- [ ] 用户确认域名、公开邮箱/简历版本及最终首页视觉。

## H. 动效专属验收（与普通视觉验收独立）

- [ ] Hero 入场为一次性视觉叙事，不出现黑屏、不可跳过片头或失控循环。
- [ ] 默认、`prefers-reduced-motion`、无 JS、触控、弱网五类情景首屏都能看到项目标题与真实画面。
- [ ] 从首页进入项目页、浏览器前进/返回、直接深链和刷新正常；跨文档转场不可用时保持原生导航。
- [ ] 所有 reveal 在 JS 异常时不隐藏正文；观察器与可选动画时间轴不存在重复初始化或泄漏。
- [ ] 视频点击前不会自动加载完整媒体；poster、播放控件、字幕/文字替代可用。
- [ ] 背景的冰晶与折射层不抢占焦点、不覆盖链接、不伤害对比度。
- [ ] GSAP 如引入，必须证明至少一个通过审美评审的多段动画确实需要时间轴，并在 reduced-motion 时降级。
- [ ] 实机检查滑动与媒体播放期间没有持续显著掉帧；记录证据而不是空泛声称 60 FPS。
