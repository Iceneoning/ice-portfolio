# 施工任务包与验收证据（供后续独立对话）

- 状态：任务包草案，尚未运行
- 目的：将设计文档转成前端小批次施工单位，避免先做复杂动效最后补静态内容。
- 每个任务单元只修改相邻职责目录，提交实际文件列表、差异、运行结果和未验证风险。

## W0：资料核验与美术预制作

**输入：** RTS 和 BA 的真实演示素材、项目职责清单、可公开简历状态。

**输出：** 作品封面候选、录屏分镜、公开资产许可表与两个首页方案。

- [ ] 核实 RTS 实际功能截图；保持“命令系统不是本人开发、多人测试未完成”的准确边界。
- [ ] 核实 BA/Lyra 的复用与独立实现范围。
- [ ] 处理素材文件命名、裁切、缩略封面和权限检查。
- [ ] 绘制一版首页静态稿、一版项目详情静态稿；再补动效示意。
- [ ] 由用户完成审美评审，不自动把暂定分镜视为最终美术方案。

## W1：工程基础与静态路由

**输入：** ADR-0001、ADR-0003、[整体架构](../architecture/01-system-overview.md)。

**输出：** 可运行 Astro + TypeScript + pnpm、全局 token、页面 skeleton。

- [ ] 初始化工程、锁定版本、MDX、Content Collections Schema。
- [ ] 根据 schema 生成卡片 view model；草稿隔离并在构建中阻断无效字段。
- [ ] 建立 `/`、`/projects/`、`/projects/[slug]/`、`/about/`、`/resume/`、404 路由。
- [ ] 检查静态构建、类型检查、深链刷新与无 JS 浏览。

**阻塞条件：** 构建不能通过、项目详情路由需手工写死、草稿泄露到正式页面。

## W2：静态视觉系统

**输入：** 评审过的设计稿、[视觉规范](../design/01-visual-system.md)。

**输出：** Header、Hero、项目卡、详情模板和多端版式。

- [ ] 开发 CSS token、主要排版、边框与冰晶装饰。
- [ ] 真实项目封面替代所有开发占位素材。
- [ ] 移动设备单列布局、技术文章溢出处理、清晰的交互控件。
- [ ] 两个代表项目可从首页直接进入详情。

**阻塞条件：** 第一屏缺少作品/UE 定位、移动端溢出、视觉风格与审美稿背离。

## W3：媒体、细节动效与无障碍

**输入：** 静态可用的 W2 页面、[动效运行时](../architecture/04-motion-runtime.md)、[分镜](../design/03-motion-storyboard.md)。

**输出：** 按需播放的 MediaViewer、局部高质量动效、兼容降级。

- [ ] 优先静态图片与 `preload=none` 视频；录屏字幕和文字说明齐全。
- [ ] CSS hover/focus 与首页一次性 reveal；有分镜需求再添加 GSAP。
- [ ] 测试原生跨文档 View Transitions；不支持时自然完整导航。
- [ ] 低运动偏好、键盘、触屏、无 JS、前进后退回归。
- [ ] 记录动效评审的通过/退回/删除结果。

**阻塞条件：** 动画未完成导致正文消失、拦截导航、视频卡首屏、键盘不可访问。

## W4：完整技术案例与内容校验

**输入：** 已授权的截图视频、经过核实的架构与代码。

**输出：** 两篇技术案例、真实的本人职责与可追溯证据。

- [ ] 完成 RTS 与 BA 的长文、架构图、实现细节、验证和限制。
- [ ] 对每项“已实现/已测试”主张做证据核对。
- [ ] 核对源码公开许可、私有信息清理与媒体授权。

## W5：发布准备与验收

**输入：** W1–W4 均合格；具备独立子域名发布授权。

**输出：** CI、预览环境、视觉回归报告、最终发布记录。

- [ ] 页面和静态资源构建通过，浏览器冒烟与链接测试通过。
- [ ] Lighthouse 与实机测量，收集媒体用量、性能和可访问性证据。
- [ ] Cloudflare 预览部署与正式子域名绑定**分别**确认。
- [ ] 发布后实际访问测试与 Git commit 回滚路径。

## 单任务交付模板

```text
任务包 ID：
本次变更范围：
使用的设计/架构/ADR 版本：
实际创建/修改文件：
构建和浏览器验证（命令、结果）：
审美验收（PASS / FAIL / NOT RUN）：
性能/可访问性（PASS / FAIL / NOT RUN）：
未验证项目与阻塞：
后续任务依赖：
```

没有执行的构建、测试与部署一律写 NOT RUN，不得以计划替代完成证据。
