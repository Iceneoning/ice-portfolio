# Winter Atelier concept illustrations

Created on 2026-10-09 using the built-in ImageGen tool for the portfolio's visual redesign. These are AI-generated decorative illustrations, not original Unreal Engine project media, screenshots, implementation diagrams, or evidence of personal game work. Visible captions in the website make this distinction explicit.

- `winter-workshop.png`: homepage winter observatory / workshop. Decorative, empty alt text.
- `winter-settlement.png`: conceptual RTS cover, snowy settlement. Not the project's actual map.
- `winter-archive.png`: conceptual Blitz Archive cover, winter library. Not an environment from Lyra or Blitz.

Astro `Image` generates responsive WebP files during build; original PNGs stay in source and are not selected by the site's image sources. Existing approved project media still takes precedence through `mediaApproved`, `cover`, and `coverAlt`.

Exact generation prompts are recorded in `prompts.md`. No CLI fallback or API credentials were used.
